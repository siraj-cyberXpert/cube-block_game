# cube-block_game# 🎮 Cube Block Runner Game

## 🌟 Project Overview
Cube Block Runner is a simple 3D browser-based runner game developed using HTML, JavaScript, and Three.js WebGL graphics.

The game features:

✅ 3D Player Character  
✅ Jump Physics System  
✅ Moving Enemy Obstacle  
✅ Coin Collection Score System  
✅ Camera Follow Effect  
✅ Sky Background Rendering
